# Belajar SKD CPNS

Aplikasi web sederhana untuk latihan SKD CPNS (TIU, TWK, TKP): tes diagnostik, latihan per materi, simulasi format SKD, dan pembahasan jawaban yang salah.

## Cara pakai
Buka `index.html` di browser. Tidak perlu instalasi. Progres belajar tersimpan di browser (localStorage).

## Catatan
- Aplikasi ini untuk latihan, bukan standar resmi BKN.
- Bank soal TWK dan TKP masih terbatas. Cek ketentuan resmi seleksi untuk jumlah soal dan ambang batas.
